# 릴레이 소설 📖

여러 사람이 함께 릴레이 소설을 쓸 수 있는 협업 웹사이트입니다!

## 기능

- 🎭 **릴레이 방 생성** - 방 이름을 지정해서 새로운 릴레이 소설 시작
- ✍️ **글쓰기 & 수정** - 텍스트 박스에서 이야기 계속 작성
- 🔗 **다른 사용자 초대** - 방 ID를 공유하면 누구나 참여 가능
- 🎲 **주제 추천** - AI가 무작위로 재미있는 스토리 시작 문구 추천
- 📝 **전체 이야기 보기** - 지금까지 작성된 전체 글 확인

## 기술 스택

- **프론트엔드**: React + JavaScript
- **백엔드**: Node.js + Express
- **데이터베이스**: Firebase / MongoDB (예정)
- **배포**: Vercel / Netlify (예정)

## 설치 및 실행

### 프론트엔드
```bash
cd frontend
npm install
npm start
```

### 백엔드
```bash
cd backend
npm install
npm start
```

## 프로젝트 구조

```
relay-novel/
├── frontend/          # React 프론트엔드
│   ├── src/
│   ├── public/
│   └── package.json
├── backend/           # Node.js 백엔드
│   ├── routes/
│   ├── models/
│   └── package.json
└── README.md
```

## 시작하기

1. 이 저장소를 클론합니다
2. `frontend`와 `backend` 폴더에서 각각 `npm install` 실행
3. 각 폴더에서 `npm start`로 개발 서버 시작
4. http://localhost:3000 에서 웹사이트 접속
